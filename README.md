# Kost1kTrade: Комплексный фреймворк для алгоритмической торговли

Kost1kTrade — это многофункциональный, событийно-ориентированный фреймворк для разработки, тестирования и развертывания алгоритмических торговых стратегий. Он включает в себя бэкенд на Python (FastAPI), сложный конвейер для количественного анализа и современный фронтенд на JavaScript для управления и визуализации.

## Ключевые возможности

*   **Продвинутая ML-методология**: В основе системы лежит модель **XGBoost**, обученная на десятках усовершенствованных признаков, включая:
    *   **Стандартизированные технические индикаторы**: Классические индикаторы (RSI, MACD и т.д.), нормализованные с помощью ATR для повышения стационарности.
    *   **Статистические и режимные признаки**: Z-score объема, а также асимметрия и эксцесс доходности для определения рыночного режима.
    *   **Циклические признаки времени**: Синус/косинус часа и дня недели для улавливания временных закономерностей.
    *   **Внешние данные**: Индекс страха и жадности, макроэкономические показатели и др.
*   **Надежная Кросс-Валидация**: Применяется `TimeSeriesSplit` в процессе гиперпараметрической оптимизации (Optuna) для предотвращения утечек данных.
*   **Автоматизированный конвейер**: Единый скрипт для полного цикла от сбора данных до обучения и оценки модели XGBoost.
*   **Динамическое управление рисками**: Расчет размера позиции на основе ATR для нормализации риска.
*   **Современный API и фронтенд**: Бэкенд на FastAPI и фронтенд на React/TypeScript для удобного управления.

## Начало работы

### Шаг 1: Необходимые компоненты

- Python 3.12+
- `pip` для установки зависимостей.
- `npm` для управления зависимостями фронтенда.
- **(Опционально) API Ключи**: Для сбора данных из внешних источников (новости, макроэкономика).

### Шаг 2: Настройка окружения

1.  **Клонируйте репозиторий.**

2.  **Настройте бэкенд:**
    *   Перейдите в директорию `kost1ktrade/backend`.
    *   Создайте файл `.env` на основе `.env.example`.
    *   **ВАЖНО:** Заполните `.env` необходимыми параметрами. Ключевые параметры для запуска конвейера:
        ```
        SYMBOLS_RAW="BTC/USDT,ETH/USDT,SOL/USDT,LINK/USDT"
        DATA_HISTORY_DAYS=1095 # ~3 года данных
        TIMEFRAME="1h"
        ```
    *   Установите зависимости. Рекомендуемый способ - через `requirements.txt`:
        ```bash
        pip install -r requirements.txt
        ```
        Или, если вы предпочитаете `pdm`:
        ```bash
        pip install --user pdm
        pdm install
        ```
    *   Инициализируйте базу данных (создаст все необходимые таблицы):
        ```bash
        python scripts/create_tables.py
        ```

3.  **Настройте фронтенд:**
    *   Перейдите в директорию `kost1ktrade/frontend`.
    *   Установите зависимости: `npm install`

## Основной рабочий процесс: Обучение модели

Система спроектирована вокруг единого автоматизированного конвейера, который подготавливает все данные и обучает **XGBoost** модели.

### Шаг 1: Конфигурация эксперимента

Все основные параметры эксперимента задаются в файле `kost1ktrade/backend/.env`. Вы можете изменять список символов (`SYMBOLS_RAW`), глубину истории (`DATA_HISTORY_DAYS`) и таймфрейм (`TIMEFRAME`).

### Шаг 2: Запуск полного количественного конвейера

Этот скрипт запускает всю цепочку подготовки данных и создания моделей для всех символов, указанных в конфигурации.

```bash
# Перейдите в директорию бэкенда
cd kost1ktrade/backend

# Запустите главный конвейер
python scripts/run_full_pipeline.py
```

Этот скрипт автоматически выполнит следующие действия:
1.  **Сбор данных**: Загрузит историю торгов и внешние данные из базы данных.
2.  **Обработка признаков**: Рассчитает новый, усовершенствованный набор признаков.
3.  **Разметка данных**: Применит метод тройного барьера для создания меток (Long, Short, Neutral).
4.  **Обучение модели**: Выполнит гиперпараметрическую оптимизацию и обучит модель **XGBoost**.
5.  **Оценка и Бэктестинг**: Проведет оценку модели на тестовых данных и выполнит бэктестинг.
6.  **Создание производственной модели**: Обучит и сохранит финальную модель, готовую к использованию.

### Шаг 3: Проверка результатов

После успешного выполнения конвейера важно проверить ключевые артефакты, чтобы убедиться в качестве модели.

## Альтернативный рабочий процесс: Иерархическая стратегия на правилах

В качестве альтернативы сложному ML-конвейеру, была добавлена более простая и интерпретируемая стратегия, основанная на строгих правилах и иерархии индикаторов ("основной квартет"). Этот подход не требует обучения модели.

### Запуск бэктеста для стратегии на правилах

Этот скрипт запускает полный цикл: загрузка данных, расчет четырех ключевых индикаторов (EMA, RSI, OBV, ATR) и прогон бэктеста на основе новой иерархической стратегии.

```bash
# Перейдите в директорию бэкенда
cd kost1ktrade/backend

# Запустите бэктест для стратегии на правилах
python scripts/run_rules_based_backtest.py --asset BTC --timeframe 4h
```

Вы можете изменить `--asset` и `--timeframe` для тестирования других инструментов и таймфреймов. Результаты бэктеста, включая ключевые метрики производительности, будут выведены в консоль.

1.  **Отчет об оценке**:
    *   **Где найти**: В консоли в конце вывода `run_full_pipeline.py` или в логах.
    *   **На что смотреть**: `Classification Report` для каждого актива.
    *   **Ключевая метрика**: `F1-Score (macro avg)`. Он показывает сбалансированную производительность по всем классам.

2.  **Сохраненные модели**:
    *   **Где найти**: `kost1ktrade/backend/models/production/`.
    *   **Что содержит**: Файлы модели (`.json`), скейлера (`.joblib`) и списка признаков (`.json`) для каждого актива.

## Запуск системы для торговли

После того как модель обучена и ее качество вас устраивает, можно запускать систему в режиме торговли.

1.  **Запустите API-сервер бэкенда**:
    ```bash
    # В директории kost1ktrade/backend
    uvicorn src.api.main:app --reload
    ```

2.  **Запустите веб-интерфейс фронтенда**:
    ```bash
    # В директотории kost1ktrade/frontend
    npm run dev
    ```

3.  **Запустите «Командира»** через эндпоинт `POST /api/master-bot/start` в документации API (`http://127.0.0.1:8000/docs`).

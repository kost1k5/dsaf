# Kost1kTrade: Комплексный фреймворк для алгоритмической торговли

Kost1kTrade — это многофункциональный, событийно-ориентированный фреймворк для разработки, тестирования и развертывания алгоритмических торговых стратегий. Он включает в себя бэкенд на Python (FastAPI), сложный конвейер для количественного анализа и современный фронтенд на JavaScript для управления и визуализации.

## Ключевые возможности

*   **Продвинутая ML-методология**: В основе системы лежит модель LightGBM, обученная на десятках признаков, включая:
    *   **Технические индикаторы**: RSI, MACD, Stochastic, Bollinger Bands и др.
    *   **Данные экономического календаря**: Учитываются важные макроэкономические события.
    *   **Мульти-таймфреймный анализ**: Используются данные с 1h, 4h и 1D для более точных сигналов.
*   **Надежная Кросс-Валидация**: Применяется `PurgedTimeSeriesSplit` для предотвращения утечек данных, характерных для финансовых временных рядов.
*   **Автоматизированный конвейер**: Единый скрипт для полного цикла от сбора данных до обучения и оценки модели.
*   **Динамическое управление рисками**: Расчет размера позиции на основе ATR для нормализации риска.
*   **Современный API и фронтенд**: Бэкенд на FastAPI и фронтенд на React/TypeScript для удобного управления.

## Начало работы

### Шаг 1: Необходимые компоненты

- Python 3.12+
- `pdm` для управления зависимостями бэкенда.
- `npm` для управления зависимостями фронтенда.
- **API Ключ от Apify**: Для сбора данных экономического календаря.

### Шаг 2: Настройка окружения

1.  **Клонируйте репозиторий.**

2.  **Настройте бэкенд:**
    *   Перейдите в директорию `kost1ktrade/backend`.
    *   Создайте файл `.env` на основе `.env.example`.
    *   **ВАЖНО:** Добавьте в `.env` ваш API-ключ от Apify:
        ```
        APIFY_API_TOKEN="ВАШ_КЛЮЧ"
        ```
    *   Установите зависимости:
        ```bash
        pip install --user pdm
        pdm install
        ```
    *   Инициализируйте базу данных (создаст все необходимые таблицы, включая новую для календаря):
        ```bash
        pdm run python scripts/create_tables.py
        ```

3.  **Настройте фронтенд:**
    *   Перейдите в директорию `kost1ktrade/frontend`.
    *   Установите зависимости: `npm install`

## Основной рабочий процесс: Обучение модели

Система спроектирована вокруг единого автоматизированного конвейера, который подготавливает все данные и обучает модели.

### Шаг 1: Конфигурация эксперимента

Основной параметр для экспериментов — **таймфрейм**. Он задается в файле `kost1ktrade/backend/src/core/config.py` в строке:
```python
TIMEFRAME: str = "4h" # Рекомендуется '4h' или '1D'
```
Перед запуском конвейера убедитесь, что выставили желаемый таймфрейм.

### Шаг 2: Запуск полного количественного конвейера

Этот скрипт запускает всю цепочку подготовки данных и создания моделей для всех символов, указанных в конфигурации.

```bash
# Перейдите в директорию бэкенда
cd kost1ktrade/backend

# Запустите главный конвейер
pdm run python scripts/run_full_pipeline.py
```

Этот скрипт автоматически выполнит следующие действия:
1.  **Сбор данных**: Загрузит историю торгов, данные Fear&Greed, новости и **события экономического календаря**.
2.  **Обработка признаков**: Рассчитает все технические индикаторы и новые признаки на основе календаря.
3.  **Разметка данных**: Применит метод тройного барьера.
4.  **Отбор признаков**: Выберет наиболее значимые и наименее коррелирующие признаки с помощью **SHAP**.
5.  **Бэктестинг и Оценка**: Проведет walk-forward валидацию и сгенерирует финальный отчет о производительности.
6.  **Создание производственной модели**: Обучит и сохранит финальную модель.

### Шаг 3: Проверка результатов

После успешного выполнения конвейера важно проверить ключевые артефакты, чтобы убедиться в качестве модели.

1.  **Отчет об оценке**:
    *   **Где найти**: В консоли в конце вывода `run_full_pipeline.py` или в логах.
    *   **На что смотреть**: `Evaluation Report for [ASSET]`.
    *   **Ключевая метрика**: `F1-Score (weighted)`. **Цель — значение > 0.55.**

2.  **График важности признаков (SHAP)**:
    *   **Где найти**: `kost1ktrade/backend/reports/[ASSET]_[TIMEFRAME]_shap_summary.png`.
    *   **Что показывает**: Какие признаки вносят наибольший вклад в предсказания модели. Позволяет оценить адекватность модели.

3.  **Список отобранных признаков**:
    *   **Где найти**: `kost1ktrade/backend/reports/[ASSET]_[TIMEFRAME]_selected_features.txt`.
    *   **Что показывает**: Финальный список признаков, которые используются в модели.

## Запуск системы для торговли

После того как модель обучена и ее качество вас устраивает (F1-score > 0.55), можно запускать систему в режиме торговли.

1.  **Запустите API-сервер бэкенда**:
    ```bash
    # В директории kost1ktrade/backend
    pdm run uvicorn src.api.main:app --reload
    ```

2.  **Запустите веб-интерфейс фронтенда**:
    ```bash
    # В директории kost1ktrade/frontend
    npm run dev
    ```

3.  **Запустите «Командира»** через эндпоинт `POST /api/master-bot/start` в документации API (`http://127.0.0.1:8000/docs`).

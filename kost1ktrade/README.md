# Kost1kTrade

Это проект трейдингового бота с веб-интерфейсом для управления и мониторинга.

## Обзор архитектуры

Проект имеет монорепозиторную структуру и разделен на две основные части:

-   `backend`: Серверная часть, написанная на Python. Отвечает за всю логику торговли, сбор данных, бэктестинг и предоставление API для клиентской части.
-   `frontend`: Клиентская часть, написанная на React. Отвечает за отображение пользовательского интерфейса.

## Запуск с помощью PM2 (Рекомендуемый способ)

PM2 — это менеджер процессов для Node.js, который позволяет легко управлять и демонизировать приложения. Мы настроили его для управления как бэкендом, так и фронтендом.

1.  **Установите PM2 глобально** (если еще не установлен):
    ```bash
    npm install pm2 -g
    ```

2.  **Запустите все приложение** (из корневой директории проекта):
    -   Эта команда запустит и бэкенд, и фронтенд в фоновом режиме.
    ```bash
    pm2 start ecosystem.config.js
    ```

### Управление приложением через PM2

-   **Мониторинг состояния**:
    ```bash
    pm2 monit
    ```
-   **Просмотр логов**:
    ```bash
    # Показать логи для всех процессов
    pm2 logs

    # Показать логи только для бэкенда
    pm2 logs kost1ktrade-backend
    ```
-   **Остановка всех процессов**:
    ```bash
    pm2 stop all
    ```
-   **Перезапуск всех процессов**:
    ```bash
    pm2 restart all
    ```
-   **Удаление из списка PM2**:
    ```bash
    pm2 delete all
    ```

## Инструкции по запуску (Вручную)

Эти инструкции помогут вам развернуть и запустить проект локально.

### 1. Предварительные требования

Убедитесь, что у вас установлены:
- **Python 3.12**
- **Pipenv** (для управления виртуальными окружениями Python). Установить можно через `pip install pipenv`.
- **Node.js** и **npm** (для управления зависимостями фронтенда).
- **PostgreSQL**. Сервер базы данных должен быть запущен.

### 2. Настройка бэкенда

1.  **Перейдите в директорию `backend`**:
    ```bash
    cd kost1ktrade/backend
    ```

2.  **Создайте и настройте файл `.env`**:
    -   Скопируйте файл `.env.example` и переименуйте его в `.env`.
    -   Откройте `.env` и заполните данные для подключения к вашей базе данных (`DB__USER`, `DB__PASS`, `DB__NAME`). Указанные по умолчанию `DB__USER=postgres` и `DB__NAME=trading_bot_data` являются стандартными. Вам нужно будет только указать свой пароль.
    -   Для использования Telegram-уведомлений и API биржи впишите соответствующие ключи.

3.  **Установите зависимости**:
    ```bash
    pipenv install
    ```

4.  **Настройте базу данных PostgreSQL**:
    -   Убедитесь, что ваш сервер PostgreSQL запущен.
    -   Создайте пользователя и базу данных, которые вы указали в `.env` файле. Например, для пользователя `postgres` и базы `trading_bot_data`:
    ```sql
    -- Войдите в psql как суперпользователь
    sudo -u postgres psql

    -- Измените пароль для пользователя postgres (замените 'ваш_пароль' на пароль из .env)
    ALTER USER postgres WITH PASSWORD 'Kostya1790';

    -- Создайте базу данных
    CREATE DATABASE trading_bot_data;
    ```

5.  **Создайте таблицы в базе данных**:
    -   Этот скрипт создаст все необходимые таблицы. Флаг `--recreate` полностью удалит старые таблицы перед созданием новых. **Внимание: это приведет к потере всех данных!**
    ```bash
    pipenv run python scripts/create_tables.py --recreate
    ```

6.  **Запустите API сервер**:
    ```bash
    pipenv run uvicorn src.api.main:app --reload
    ```
    Сервер будет доступен по адресу `http://127.0.0.1:8000`. Вы можете посмотреть доступные эндпоинты по адресу `http://127.0.0.1:8000/docs`.

### 3. Настройка фронтенда

1.  **Перейдите в директорию `frontend`**:
    ```bash
    cd kost1ktrade/frontend
    ```

2.  **Установите зависимости**:
    ```bash
    npm install
    ```

3.  **Запустите сервер для разработки**:
    ```bash
    npm run dev
    ```
    Веб-интерфейс будет доступен по адресу `http://localhost:5173/`.

После выполнения всех шагов, откройте `http://localhost:5173/` в вашем браузере, и вы должны увидеть рабочий интерфейс, который взаимодействует с бэкендом.

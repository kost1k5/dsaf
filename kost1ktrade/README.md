# Kost1kTrade

Это проект трейдингового бота с веб-интерфейсом для управления и мониторинга.

## Обзор архитектуры

Проект имеет монорепозиторную структуру и разделен на две основные части:

-   `backend`: Серверная часть, написанная на Python. Отвечает за всю логику торговли, сбор данных, бэктестинг и предоставление API для клиентской части.
-   `frontend`: Клиентская часть (веб-сайт). На данный момент содержит временную страницу-заглушку.

## Бэкенд (Backend)

Бэкенд построен на Python 3.12 с использованием фреймворка FastAPI.

### Настройка окружения

1.  **Перейдите в директорию `backend`**:
    ```bash
    cd kost1ktrade/backend
    ```
2.  **Создайте и настройте файл `.env`**:
    *   Скопируйте файл `.env.example` и переименуйте его в `.env`.
    *   Откройте `.env` и внимательно заполните все необходимые переменные. Как минимум, вам нужно указать данные для подключения к базе данных (`DB__...`) и для уведомлений в Telegram (`TELEGRAM_...`).
    *   Для реальной и/или демо-торговли, сгенерируйте **НОВЫЕ** API ключи на бирже OKX и впишите их в соответствующие поля (`OKX_REAL__...` и `OKX_DEMO__...`).

    **ВАЖНО:** Никогда не публикуйте свои секретные ключи и файл `.env`.

3.  **Установите зависимости**:
    ```bash
    pipenv install
    ```
4.  **Создайте таблицы в базе данных**:
    *   Убедитесь, что ваш сервер PostgreSQL запущен.
    *   Выполните скрипт для создания таблиц:
    ```bash
    pipenv run python scripts/create_tables.py
    ```

#### Устранение неисправностей (Troubleshooting)

-   **Ошибка `столбец "..." в таблице "..." не существует` (column "..." does not exist):**
    Эта ошибка возникает, если вы уже создавали таблицы, а потом мы в коде добавили в них новые колонки. Скрипт `create_tables` не изменяет существующие таблицы.
    **Решение:** Зайдите в вашу базу данных PostgreSQL и выполните команду `DROP TABLE backtest_results;` (или для другой таблицы, на которую ругается). После этого снова запустите `pipenv run python scripts/create_tables.py`, и таблица будет создана с правильной, новой структурой.

### Использование

#### Запуск API сервера

API сервер предоставляет эндпоинты для управления ботом (в будущем будет использоваться сайтом).

```bash
pipenv run uvicorn src.api.main:app --reload
```
Сервер будет доступен по адресу `http://127.0.0.1:8000`. Вы можете посмотреть доступные эндпоинты по адресу `http://127.0.0.1:8000/docs`.

#### Запуск Telegram-бота

Интерактивный бот запускается как отдельный процесс и позволяет управлять бэктестами и оптимизацией.

1.  Убедитесь, что вы указали `TELEGRAM_TOKEN` и `TELEGRAM_CHAT_ID` в вашем `.env` файле.
2.  Запустите бота:
    ```bash
    pipenv run python -m src.notifications.telegram
    ```

**Доступные команды:**
- `/start`: Приветствие и список команд.
- `/status`: Показывает статус сигнального и сеточного ботов.
- `/backtest`: Запускает бэктест для стратегии `SmaCrossoverStrategy` и присылает отчет.
- `/optimize`: Запускает оптимизацию для `SmaCrossoverStrategy`.
- `/walkforward`: Запускает Walk-Forward анализ для `SmaCrossoverStrategy`.

#### Запуск бэктестера

Скрипт `run_backtest.py` позволяет протестировать любую стратегию на исторических данных.

```bash
pipenv run python scripts/run_backtest.py
```
Скрипт попытается загрузить данные из БД. Если данных нет, он автоматически скачает их с биржи **OKX** и проведет бэктест.

#### Запуск Ботов (Live Trading)

В проекте существует два типа ботов, которые управляются через API.

##### 1. Сигнальный бот (Signal Bot)

Этот бот работает на основе простых сигналов (BUY/SELL) от стратегий типа SMA, RSI, и т.д.

-   **Статус:** `GET /signal-bot/status`
-   **Запуск:** `POST /signal-bot/start` (тело запроса: `{"mode": "demo"}`)
-   **Остановка:** `POST /signal-bot/stop`

##### 2. Сеточный бот (Grid Bot)

Этот бот работает по логике сеточной торговли.

-   **Статус:** `GET /grid-bot/status`
-   **Запуск:** `POST /grid-bot/start` (тело запроса: `{"mode": "demo", "symbol": "BTC/USDT", "amount_per_grid": 0.001, "grid_range_low": 50000, "grid_range_high": 60000, "num_grids": 10}`)
-   **Остановка:** `POST /grid-bot/stop`

**Пример запуска сеточного бота через `curl` (Linux/Mac/WSL):**
```bash
curl -X POST -H "Content-Type: application/json" \
-d '{"mode": "demo", "symbol": "BTC/USDT", "amount_per_grid": 0.001, "grid_range_low": 50000, "grid_range_high": 60000, "num_grids": 10}' \
http://127.0.0.1:8000/grid-bot/start
```

**Пример для Windows PowerShell (100% рабочий вариант):**
```powershell
$body = @{
    mode = "demo";
    symbol = "BTC/USDT";
    amount_per_grid = 0.001;
    grid_range_low = 50000;
    grid_range_high = 60000;
    num_grids = 10
} | ConvertTo-Json

Invoke-WebRequest -Uri http://127.0.0.1:8000/grid-bot/start -Method POST -ContentType "application/json" -Body $body
```
(Примечание: Реальная фоновая работа ботов пока не реализована до конца из-за особенностей окружения, но API для управления ими уже на месте).

### Основные библиотеки

-   `fastapi`, `uvicorn`: Для создания и запуска API.
-   `sqlalchemy`, `psycopg2-binary`: Для работы с базой данных PostgreSQL.
-   `pipenv`: Для управления зависимостями.
-   `ccxt`: Для работы с API криптовалютных бирж.
-   `pandas`, `numpy`: Для анализа данных и вычислений.
-   `python-telegram-bot`: Для отправки уведомлений в Telegram.

### Структура бэкенда

Исходный код находится в `backend/src`.
-   `src/api`: Логика API-эндпоинтов.
-   `src/core`: Общие компоненты, конфигурация и управление состоянием.
-   `src/database`: Модели данных (SQLAlchemy) и логика работы с БД.
-   `src/notifications`: Модули для отправки уведомлений (например, Telegram).
-   `src/strategies`: Место для реализации торговых стратегий. На данный момент реализованы:
    -   `SmaCrossoverStrategy` (Пересечение скользящих средних)
    -   `RsiStrategy` (Индекс относительной силы)
    -   `BollingerBandsStrategy` (Линии Боллинджера)
-   `src/trading`: Основная логика торговли, интеграция с биржей.
